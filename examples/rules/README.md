# 侧转反击型 2v2 Agent

该行为树不争取开局直线首射。两机分别向目标方位左右偏置47°，保持58秒固定侧转航段后再重新压进；收到来弹时优先判断能否还击，不能还击就按发射者反方向高速拖曳。它用于测试对手能否处理拒绝正面对冲和反复重新接敌。

## 主要规则

- 两机分别分配敌机，开局向相反方向固定侧转。
- 侧转航段 Mach 1.18，上下分离。
- 与其他三类基础Agent使用相同动态包线：迎头150 km、侧向115 km、逃逸85 km。
- 受到攻击时仍需满足动态包线，并允许机头误差36°以内还击。
- 发射或来弹逃逸使用 Mach 1.4、72秒固定拖曳航段。
- 固定航段只在进入阶段时计算一次，避免每秒累加偏角形成盘旋。

## 验证定位

统一发射包线后的五场景、交换红蓝30局循环赛：19胜11负、零违规，综合得分率63.3%。它对强攻型6胜4负、对集火接力型8胜2负、对诱饵侧击型5胜5负；五个场景的最低得分率为50%，蓝方60%、红方66.7%。因此它被选为进入大模型自我迭代的初始母版，但这仍只是有限对手池内的稳健性证据，不是对未知Agent的泛化证明。
